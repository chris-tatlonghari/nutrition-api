# Codex Preferences

## UI/UX
- Prefer Bootstrap-style structure and layout conventions.
- Avoid purple; lean into rich reds (primary: rgb(168 21 42)) for food-related branding.
- Use clean, bold typography and preserve existing visual language unless asked to rework.

## Implementation
- Favor composability: extract shared UI into partials or components.
- Keep styling centralized with reusable CSS variables when possible.
